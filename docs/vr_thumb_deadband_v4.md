# VR 拇指滤波与死区 v4

本次针对静止拇指抖动和整手移动时手指变形继续加强主端采集处理；不修改 canonical 到从端的滤波策略。

- Unity 桥接器使用腕点、食指根部、中指根部、小指根部构造统一正交掌心坐标系，在该坐标系中滤波手指，再整体变换回外部坐标。整手平移和转动不会按不同手指滤波增益分别处理。
- 拇指局部位置软死区 1.5 mm，其余关节点 0.8 mm；拇指最低截止频率 0.18 Hz，局部速度增益由 20 降至 5，限制噪声触发的带宽增加。
- 几何输入映射前新增归一化拇指弯曲／横摇特征死区，分别为 0.025／0.035。滤波带宽 0.45–3 Hz，最大特征变化速率 1.5/s。持续动作可以穿过死区，不会永久锁住自由动作。
- 已确认的捏合仍由 VR 原生接触锚点保持。特征滤波位于 RatioToTarget 之前，不是对电机目标追加滤波。

需要重启 Unity 手部桥接器及手部接收进程；只更换 EXE 不会加载 Python 中的掌心局部滤波。接收程序版本标识：vr-palm-local-thumb-deadband-v4；骨架滤波元数据名称：one_euro_palm_local_deadband_v4。

本次按用户要求不运行测试，只有 Release 编译。上述参数是本次设定值，不是经过测试得到的性能保证；代价是细微动作跟随更迟钝。

用户确认后，食指捏合 ID1 已从 750 改为 800。预编程完整目标为 [800, 300, 350, 2000, 2000, 2000]；VR 与数据手套共享标定中的食指接触锚点 ID1 同步为 800。ID1=拇指弯曲、ID2=横摇、ID3=食指。代码约定 2000 张开，较小值更闭合。本次数值调整不涉及 C++ 源码，不需重新编译；重启主端后端与手部接收进程加载。
