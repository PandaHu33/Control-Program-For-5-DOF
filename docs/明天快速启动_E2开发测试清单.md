### ⚠️ 必须修的两个坑（不修明天必卡）

**坑 1（会静默失效，第一行就改）**：`hand_telemetry_loop()` 现在**只接受 schema {1,2,3}**：

```python
# bridge.py L2225（现状）
if payload.get("type") != "wa100_recording_state" or int(payload.get("schema_version", 0)) not in {1, 2, 3}:
    continue
```

你把手端 telemetry 升到 schema 4 之后，**这一行会把所有新遥测整包丢弃**，bridge 永远读不到 `admittance_mode/retreat`，UI 干预条件永远不成立，且一切"正常"——最危险的静默失效。改法：`{1, 2, 3}` → `{1, 2, 3, 4}`，并对 schema<4 的 payload 把新字段当"未激活"处理（fail-open）。

**坑 2（审计块匹配要精确）**：计划说"把匹配当前 source/time 的 audit 块附加到 canonical goal"——50 Hz 下按时间模糊匹配会挂错行。前端在 `canonical_wrist_adapter` 里带上 `wrist source_seq + source_time_ns`，bridge 以 `(source_seq, source_time_ns)` 为键存审计块、以同键取回。不要让 bridge 靠"时间最接近"猜。

### ⚠️ 一个消融设计问题（强烈建议加第 4 个模式）

计划把"构型调制导纳"和"臂整体退让"**都塞进 Holistic=2**，HandOnly=1 保留 legacy。这样 A1 vs A2 混淆了两个因素（手侧升级 + 臂侧退让），论文 E2/E4 消融无法归因。

**建议**：`AdmMode` 加一个值 `HandConfig=3`（构型调制手导纳、**无**臂退让）。成本几乎为零——HandConfig 与 Holistic 共用同一段构型调制动力学，臂退让只 gate 在 `mode==2`。测试矩阵变成干净的 4 格：

| 模式 | 手导纳 | 臂退让 |
|---|---|---|
| A0 Off | 无（900/850 锁存） | 无 |
| A1 HandOnly | legacy | 无 |
| A3 HandConfig | 构型调制（升级） | 无 |
| A2 Holistic | 构型调制（升级） | 有 |

若时间实在不够，退而求其次：**报告里必须写明 A2 是复合干预**，不能写成"臂手整体退让带来的改善"。

2. **命令解析**：`AdmModeToString()` + `ParseAdmittanceModePacket()`，只接受 `{"type":"set_admittance_mode","schema_version":1,"mode":0|1|2|3}`；在 `ParseUnityUdpPacket()`（L1271）里与 `ParseH5ControlPacket` 并列解析；切换只改柔顺策略，不动 `ControlMode`、目标位、canonical/native fallback，打印明确日志。
3. **`ComplianceControlLoop()`（L1311）**：
   - 模式切换 bumpless：以有效 `current_pos` 重置 `desired_filters`、清速度与不兼容 offset；A1↔A3↔A2 保留连续状态；退出 Holistic 立即清零 retreat；离开 Off 清除 hold。
   - **Off**：仍做反馈归一化、电流滤波、desired slew、`SyncWriteRead()`；任一通道 raw 或 filtered > 900 mA 锁存实际位置，二者 < 850 mA 释放。
   - **HandOnly**：原样保留 L1439–1499 的 legacy 触发迟滞/soft release/二阶积分/限速/offset clamp，仍用原始 `FORCE_THRESHOLD=500`、`FORCE_GAIN=7.0`（L167–171）。
   - **HandConfig / Holistic**：`closure_ratio=clip((2000-current_pos)/2000)`（无效位置用最近有效值）；动态 gain/trigger 替换 legacy 对应值，其余动力学共用 A1；**Holistic 额外**算 `load_evidence=0.4*R_count+0.6*R_peak`，τ=0.1s 低通、0.25/0.12 迟滞 → `g_retreat_level/active`；**HandConfig 的 retreat 恒为 0**。
4. **telemetry 升 schema 4**（L1527 起）：加 `admittance_mode`、六通道 closure、retreat level/active、Off hold、三组调试数组；非 Holistic 时 retreat 与调试量显式归零。
5. **`admittance_log.csv`**（L1502–1516）：保留原列，追加模式/closure/retreat/hold/gain/trigger/evidence。
6. **编译**：`cmake --build build --config Release`；空载验证三（四）模式可切 + schema 4 字段出现。
