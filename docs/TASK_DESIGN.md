# WA100 灵巧手抓取任务重新设计与过流缓解方案

> 日期：2026-08-17　状态：方案建议（尚未实施）　适用范围：P0/E1 及后续 E2/E3 场景组织
> 关联文档：[E1 Canonical no-send dry-run SOP](E1_CANONICAL_DRY_RUN_SOP.md)、[第一阶段形态—负载一致性抓持判别（monitor-only）](perception_assist_monitor_phase1.md)、[论文完整大纲](水下电动机械臂手一体化遥操作系统_论文完整大纲_命令交互一致性重构.md)

## 1. 问题现象与根因

**现象**：WA100 灵巧手在抓取（尤其是刚性物体）时极易触发过流保护而堵转卡死，随后需要清错/重新使能（"重启"）才能恢复；实验方案难以按原设计执行。

**根因**：

- WA100 为 6 电机、5 指、拉索驱动的弱力水下灵巧手，各关节过流保护阈值可配（`SetCurrentProtection`，300–1500 mA），堵转触发 `LA_ERROR_STALL`/过流故障。
- 抓取刚性物体时，手指被物体刚性阻挡，而控制仍以跟随方式持续向目标位置发力，接触瞬间电流冲顶 → 保护跳闸。
- 现有防线（接收端 50 Hz 柔顺循环、软卸力、拉索单向柔顺、perception-assist 的 `OVERLOAD` 提示）都是"事后"或"旁路"手段：柔顺循环对刚性接触瞬间的堵转无能为力；`OVERLOAD` 为 monitor-only，不停止闭合，也不替代 WA100 本地保护。
- 手套全量程映射 + 快速闭合会放大上述问题；死区补偿（WA100 `99ad4de`）只解决起始段，不解决末端堵转。

**结论**：任务设计应从"力闭合抓取"转向"**姿态 + 臂运动 + 被动支撑**"——手只做形状，力由重力、磁力、粘性、浮力承担。这同时满足论文大纲 4.2「任务无关的场景组织」：抓取不再是唯一任务，而是触发手部交互证据的一种物理片段。

## 2. 设计原则

1. **零闭合优先**：能用钩、套、推、按完成的，不用握。
2. **软物优先**：必须闭合时，选柔顺物体（形变吸收闭合力）。
3. **接触即停**：闭合逼近目标时慢速、分步、留余量，一旦电流残差上升立即停止（本地保护前介入）。
4. **保持不顶**：闭合到位后切 `Idle` 保持，不持续跟随目标。
5. **工装优先**：低成本工装（磁铁、钩子、绑带、勺铲）优先于让灵巧手"硬抓"。
6. **可标定**：任务事件应能被 perception-assist 观测器干净地分类（`FREE`/`EARLY_CONTACT`/`GRASP_CANDIDATE`/`GRASP_SUPPORTED`/`OVERLOAD`）。

## 3. 过流缓解措施（控制/配置层，不改硬件）

| 手段 | 做法 | 效果 |
| --- | --- | --- |
| 慢速分步闭合 | 手套/预设目标按小步长斜坡逼近（每次 ≤100 units，间隔 ≥50 ms），不直接跳满闭合 | 给电流泄放时间，堵转概率大降 |
| 手套映射缩比 + 钳位 | `glove_thumb_mapper` 增加全局 closure gain（约 0.6–0.7）与目标上限 | "握拳"最多闭到约 70%，末端留缓冲 |
| 抓住即切 idle | 闭合到位后切 `Idle`（holding current position），不持续跟随 | 消除"一直顶"产生的持续电流 |
| `OVERLOAD` 当停手信号 | 操作者看到提示即停止闭合或微张（先做操作员训练） | 在硬件保护跳闸前介入 |
| 预抓取位形 | 先到"预抓取/半握"停在离物体 5–10 mm，再微闭合，靠臂上提完成搬运 | 接触力最小化 |
| 提高过流阈值（谨慎） | 确认机构允许后 `SetCurrentProtection` 300→1500 mA | 抓取窗口变大；注意机械与安全风险 |
| 水下运行 | 水中浮力 + 冷却，抓漂浮物几乎不需要手指力 | 过温/过流双缓解 |

> 其中"慢速分步闭合 + 电流阈值自动停止闭合"可先在接收端实现为最小本地版本（对应论文 E4 单向辅助的本地前身，仍以 monitor-only 为默认）。

## 4. 任务分类与操作定义

### 4.1 A 类：零夹持力（首选，所有 E1 条件可用）

| 任务 | 手势/预设 | 操作步骤 | 为什么不过流 | 预期观测器事件 |
| --- | --- | --- | --- | --- |
| 绳套立柱（套绳子） | 拇指+食指成环 / OK 手势 | 手成型后由臂移动套入立柱、瓶颈、钩子，套上后臂上提 | 全程无接触闭合，靠结构限位 | `FREE` → 可能 `EARLY_CONTACT`（套入瞬间轻碰） |
| 钩挂提环 | "钩拉"预设 | 钩住杯子提手/钥匙圈/登山扣/S 钩/扎带环，重力自锁后提升 | 手指静态成型，零发力 | `FREE` |
| 磁吸末端 | 任意静态手势 + 指尖/掌心肌贴磁铁 | 吸回形针、垫片、螺丝、铁片并搬运 | "抓取"= 吸附，电流零风险 | `FREE`（几乎无事件，属干净基线） |
| 推/按/拨/滑 | 一指/拳手势 | 按按钮、推滑块、拨开关、拧旋钮 | 臂出力，手不闭合 | `EARLY_CONTACT`（边缘/障碍）或 `FREE` |
| 穿环/穿线 | 拇指+食指微夹 | 微夹粗绳/细杆穿过挂环或孔洞 | 微闭合 + 精度任务，几乎不发力 | `EARLY_CONTACT` |
| 绑笔按压 | 笔/触控笔绑于手指间 | 按压键盘、平板、按钮 | 手只做支撑 | `FREE` |
| 铲/舀 | 勺/铲扎带固定于手 | 舀泡沫球、珠子、沙 | 舀取替代抓取 | `FREE` |

### 4.2 B 类：柔顺物体（闭合也不跳闸）

| 任务 | 物体示例 | 操作步骤 | 为什么不过流 | 预期观测器事件 |
| --- | --- | --- | --- | --- |
| 软物抓放 | 海绵、泡沫球、泡沫积木、软胶球、半充气气球、毛绒玩具、布料、纸巾 | 全握后搬运至目标区 | 闭合力被物体自身形变吸收 | `GRASP_CANDIDATE` → `GRASP_SUPPORTED` |
| 缆线抓—牵引—布放 | 柔性缆线、绳子、胶管、数据线（多股优于单股） | 抓取 → 牵引 → 盘绕/布放 | 柔顺形变 + 可滑移泄力 | `EARLY_CONTACT` → `GRASP_CANDIDATE` |
| 网兜/布袋提运 | 网兜、布袋 | 抓袋口，臂上提整袋 | 大面积接触、压强大幅降低 | `GRASP_SUPPORTED` |
| 橡皮筋套入 | 橡皮筋 | 手指撑开橡皮筋套到立柱/物体上 | 手只做张开动作 | `FREE` |

### 4.3 C 类：低力精定位（喂给 E2/E3 证据链）

环套锥形柱堆叠、乒乓球拨入坑、缆线穿环布放、杯子提手钩挂搬运、钥匙圈逐一套钩、泡沫块插入—拔出。

这些任务能自然产生从 `EARLY_CONTACT` 到 `GRASP_SUPPORTED` 的完整事件序列，且不会越过 `OVERLOAD`，perception-assist 数据干净、可标注。

### 4.4 D 类：扩展/天马行空（低成本可落地）

| 任务 | 做法 | 要点 |
| --- | --- | --- |
| 手变吊钩 | 腕部挂载钩子/吊环，机械臂当吊机搬运 | 手完全不参与力 |
| 水下捞球 | 水池中捞漂浮乒乓球/海洋球 | 浮力顶住，不需要夹紧力 |
| 指尖写画 | 笔绑在手指间，纸板/水写布上书写描线 | 微力 + 纸面反力 |
| 巡检任务 | 手绑小相机/手电沿轨道移动扫视 | 纯粹臂运动 |
| 推物进槽 | 物体放斜槽/平台，手推/拨让其滚入目标区 | "自动售货机"式取物 |
| 翻页/叠积木 | 指尖拨动软页、叠轻木积木 | 低力接触 |

## 5. E1 四条件适配与主任务串

E1 需公平比较键盘/手柄/VR/手套四种主端，任务**不能考验精细力控制**（键盘与手柄在此最弱）。推荐：

1. **机制标定场景**（沿用 perception 文档"最小实机验证"四步）：自由开合（空载）→ 边缘轻触 → 软物包覆 → 稳定保持 → 风险受载（接近但不越过安全边界）。
2. **E1 主任务串**（一次 episode 三个动作）：**绳套立柱 → 钩挂提环 → 推按钮**，全程零力闭合。
3. **跨动作场景**：缆线抓—牵引—布放（B 类），对应论文 4.2。

条件适配参考：

| 条件 | 臂侧 | 手侧 | 推荐任务组合 |
| --- | --- | --- | --- |
| `M1-PICO` | PICO 手部追踪 | VR 手部追踪 | 绳套立柱、推按钮、水下捞球 |
| `M2-VR-GLOVE` | VR 手柄增量 | 手套操控 | 钩挂提环、套环堆叠、缆线布放 |
| `M3-GAMEPAD-GLOVE` | 手柄位置控制 | 手套操控 | 推/拨/滑、磁吸、铲/舀 |
| `M4-KEYBOARD-GLOVE` | 键盘位置控制 | 手套操控 | 推按钮、软物抓放、网兜提运 |

## 6. 预期观测器事件对照

| 任务类型 | 期望状态序列 | 不应出现 |
| --- | --- | --- |
| 零闭合任务 | `FREE`（偶发 `EARLY_CONTACT`） | `GRASP_CANDIDATE`/`OVERLOAD` |
| 软物任务 | `EARLY_CONTACT` → `GRASP_CANDIDATE` → `GRASP_SUPPORTED` | `OVERLOAD` |
| 精定位任务 | `EARLY_CONTACT` ↔ `FREE` 交替 | `OVERLOAD` |
| 过载对照 | 刻意闭合至 `OVERLOAD` 提示（人工标注） | —— |

抓取成功结论仍须人工、视觉或经安全评审的保持判据确认（`grasp_success_confirmed=false` 固定不变）。

## 7. 实施建议（代码改动清单）

按性价比排序，待评审后实施：

1. **接收端慢速闭合 + 电流自动停止**：`wa100-sdk-publish/examples/udp_receiver_unity.cpp` 增加闭合目标斜坡（步长 ≤100 units）与电流阈值停止（超过阈值即保持当前目标并提示，默认不自动回退）；沿用 50 Hz 柔顺循环。
2. **手套映射全局缩比**：`glove_thumb_mapper` 增加 closure gain 与目标上限配置（默认 0.7），保留死区补偿。
3. **UI 提示强化**：H5 显控在 perception-assist `OVERLOAD`/`EARLY_CONTACT` 时给出醒目提示，并增加"慢速闭合"开关。
4. **预抓取位形标定**：按当前标定流程新增"套绳环"、"钩挂"两个静态位形预设。
5. **工装清单**：磁铁、S 钩、登山扣、扎带、勺铲、软泡沫球/球、粗绳、橡皮筋、提环杯（采购清单另附）。

## 8. 风险、边界与记录规则

- 提高过流阈值属于机械风险决策，须确认机构与减速器余量，记录在实验台账中；默认不改变。
- 空载闭合基线、各通道开闭端点必须在修改任务前按 perception 文档完成标定，否则观测器输出 `valid=0`，不参与抓持推断。
- E1 正式取数前，任务变更属于实验条件变更：更新 SOP 冻结项并记录任务定义、工装、物体规格、手势预设版本。
- 统计边界（论文 4.4）：同一对象上的连续往返不能全部当独立样本；报告独立 trial 数、操作者、对象/工装、介质、速度和标定版本。
- **配置一致性检查**：Canonical v4 只允许 `control_ui/wa100_kinematics_model.json`；正式取数前需冻结程序显示的 WA100 `calibration_id` 与 SHA-256。
