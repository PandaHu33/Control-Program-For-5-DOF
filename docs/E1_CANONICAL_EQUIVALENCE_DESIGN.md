> 一句话命题：**E1 不是比"哪个主端好"，而是证"在 canonical 中间态上，设备身份应当消失、语义内容应当保留"。**

## 0. 把 E1 的假设重新说清楚（可证伪）

原 TASK_DESIGN/SOP 里 E1 侧重"四条件公平对比 + no-send dry-run"。这里把它收紧为一条**可证伪的等价性假设**：

> 设操作者在同一意图（同一参照轨迹 / 同一手势）下，用任意主端条件 $d \in \{\text{PICO, VR, Gamepad, Keyboard}\}\times\{\text{vision, glove}\}$ 产生 canonical 中间态流 $z_d(t)$。
> 那么对任意 $d_1, d_2$，同一语义的 $z_{d_1}$ 与 $z_{d_2}$ 之间的距离，应**显著小于**同一设备下不同语义之间的距离。

形式化：

$$
\underbrace{d\big(z_{d_1}^{g},\, z_{d_2}^{g}\big)}_{\text{同语义·跨设备}}
\;\ll\;
\underbrace{d\big(z_{d}^{g_1},\, z_{d}^{g_2}\big)}_{\text{同设备·跨语义}},
\qquad
g_1 \neq g_2.
$$

这是"功能命令等价"（paper 0.9 的核心操作性概念）在中间态层面的直接、可测形式。它同时覆盖**腕部 5-DoF 轨迹**与**手部 21 节点骨架**两个子空间。

**反例即证伪**：只要"同语义跨设备距离"和"跨语义距离"不可分（separation ratio 不显著 < 1），就说明 canonical 层没有把设备身份抽象掉，等价性不成立。

## 1. "中间态"到底比什么：把 canonical_goal 拆成可独立度量的子空间

`control_ui/canonical_goal.py` 的 `canonical_goal` 就是"中间态"。它天然分成四个可比部分：

| 子空间 | 字段 | 维度 | 语义 | 谁在比 |
|---|---|---|---|---|
| **腕部轨迹（绝对）** | `wrist_pose_C.position_m` + `orientation_xyzw` | 3 + 1(roll) | 末端在 canonical 世界系 C 下的位姿 | 4 个 wrist source |
| **腕部增量（速率）** | `adapter_wrist_delta` | 6（含不可支持维恒 0） | 每次更新的平移/旋转增量 | 4 个 wrist source |
| **手部六维状态与 21 点骨架** | `hand_position_units` / `hand_skeleton_C` | 6 / 21×3 | WA100 六通道与同模型 FK 点 | 3 个 hand source |
| **下游真实命令** | `final_targets.arm_target_q_rad`(4) / `hand_target_units`(6) | 4+6 | 真正下发给臂/手的命令 | 全条件 |
| **流质量** | `validity.wrist_dof_mask` / `hand_dof_mask`、`source_state.*_age_sec`、`seq` 连续性 | — | 有效性、陈旧、丢包 | 全条件 |

**关键结构性洞察（这是让实验可行的前提）：**

E1 的四个条件其实是 **4 个 wrist source × 2 个 hand source** 的叉积，不是 4 个无结构的"条件"：

```
wrist:  pico_wrist | vr_controller | gamepad | keyboard     (4 种)
hand :  pico_hand  | data_glove                             (2 种)

M1-PICO          = pico_wrist     + pico_hand
M2-VR-GLOVE      = vr_controller  + data_glove
M3-GAMEPAD-GLOVE = gamepad        + data_glove
M4-KEYBOARD-GLOVE= keyboard       + data_glove
```

推论：

1. **手部 WA100 6-DoF/21 点 FK 等价性 = PICO 视觉 vs 数据手套**，是两种传感模态映射到同一六通道构型后的收敛问题；21 点只用于统一几何观测，不增加自由度。
2. **腕部 5-DoF 等价性 = 4 种控制模态**（绝对追踪 / 增量手柄 / 位置摇杆 / 速率键盘）的收敛问题。
3. 因此实验拆成两条正交子实验，再合成全条件。**不要一次做 4×2 全因子**（paper 4.3 的同一条纪律）。

## 2. 最难的一步：参照轨迹从哪里来

横向对比的前提是"大家跑的是**同一条**轨迹"。但 keyboard 只能离散增量、gamepad 只能有限轴速率、PICO 给绝对位姿、VR 给增量——它们的"原生可表达集"不同。所以参照**必须定义在 canonical 空间**，而不是任何设备的原生空间。

### 2.1 三种参照来源（从强到弱、从确定到人在环）

**S1 · 脚本化黄金输入（确定性等价，无人在环）**
- 写一个 `reference_canonical.jsonl`：给定腕部 $\Delta R(t)$（平移+roll）与手部关键帧序列 $S(t)$。
- 对每种设备写一个**脚本化驱动器**：按各自原生输入格式，以名义速度复现同一条 $\Delta R(t)$（键盘=定时按键、手柄=脚本化摇杆偏转、VR=脚本化增量、PICO=脚本化位姿）。
- 通过各自 adapter 后得到 $z_d(t)$，与参照比较。
- **回答**：框架是否"设备透明"——同一语义命令经过不同 adapter 是否得到同一中间态（在各自离散化误差内）。
- 优点：完全排除操作者方差；缺点：不包含人操作的抖动/时延，但那些恰恰是"设备属性"，应当单独报告而非算进等价性。

**S2 · 幽灵跟随（ghost-following，人在环但意图受控）**
- 在 sim/VR 里显示一个移动的"幽灵"（腕部路径 + 手部形状），操作者用每种设备去追它。
- 参照 = 幽灵轨迹 $R(t)$，对四种条件完全一致。
- **回答**：在"大家想做同一件事"的前提下，中间态是否相似。
- 这是最贴近"不同主端跑相似轨迹"字面意思的设计，也是用户点名的场景。

**S3 · 同一物理运动的同步多模态采集（同手同刻、真值完全一致）**
- **手部**：操作者**同时**戴 Hi5 手套，且 PICO 追踪**同一只**手。同一物理手势、同一瞬间 → `data_glove` 与 `pico_hand` 两路同时出 canonical 骨架 → 直接比对。
- **腕部**：操作者手里握 VR 手柄，且 PICO 追踪同一手腕 → `vr_controller` 与 `pico_wrist` 同时出 canonical 腕位姿 → 直接比对。
- **回答**：这是最强的证据——真值字面相同，唯一变量是传感模态/映射。任何残差都是"模态映射误差"，而 canonical 层的目标正是把这个残差压到语义无关。
- keyboard/gamepad 不放在手上，无法参与 S3；它们用 S1/S2 覆盖。

> 建议落地顺序：**S1（先证明框架等价，成本最低、最可证伪）→ S3（手部最强证据）→ S2（人在环主实验）**。

### 2.2 参照轨迹要"故意平凡"和"故意分层"

- **腕部**：低带宽、各设备都能跟上的路径——XY 平面正方形/圆/八字 + 一段 Z 下探 + 一段 roll 旋转，速度放慢到键盘步进可跟。
- **手部**：一组**canonical 手势字母表**（见 §4.2）作为关键帧，中间用慢速插值过渡；keyboard/gamepad 的手部走手套，不受离散限制，所以手部轨迹对 M2–M4 是连续的、只有 M1 用 PICO 视觉连续。
- 每条轨迹分**"形状成分"**（不依赖速度）与**"时序成分"**（依赖设备带宽），两者必须分开报告（见 §6）。

## 3. 相似度度量：腕 5-DoF 与手 21-DoF 分开、分粒度

所有距离先做**锚点对齐**（减去各自初始位姿，消掉绝对锚点差异）与**DTW 时间规整**（消掉速度/带宽差异），再在规整后采样点上算残差。时间规整量本身记为"时序误差"，单独报告。

### 3.1 腕部（5-DoF）

| 指标 | 定义 | 单位 | 用途 |
|---|---|---|---|
| 位置形状误差 | DTW 后逐点欧氏距离的 mean / P95 / max | mm | 主指标 |
| roll 形状误差 | roll 角差（或 SO(3) 测地距，roll 子空间） | deg | 主指标 |
| 下游命令误差 | $\|arm\_target\_q_{d_1}-arm\_target\_q_{d_2}\|$ | rad | "功能等价"最直接代理 |
| 速度方向一致性 | 规整后速度单位向量点积的均值 | [−1,1] | 是否"朝同一方向动" |
| 时序误差 | DTW 累计 warp 量 / 时长 | s 或 % | 设备带宽属性，不算等价失败 |
| 漂移 | 位置误差随时间的一阶趋势 | mm/s | 区分积分漂移 vs 形状差 |

### 3.2 手部（21-DoF = 21 节点骨架）

| 指标 | 定义 | 单位 | 用途 |
|---|---|---|---|
| 骨架 RMS / max | 21 节点逐点欧氏距离（腕系下，已对齐） | mm | 主指标 |
| 逐指屈曲误差 | 由骨架反解每指 MCP/PIP/DIP 屈曲角，逐 DoF 误差 | deg | "21 DoF"的可解释分解 |
| 拇指对掌误差 | 拇指 pitch/yaw 两自由度误差 | deg | 最关键的单指指标 |
| 捏合距离误差 | thumb_tip↔index_tip 距离 | mm | 功能语义 |
| 开度 C 误差 | 由骨架算整体闭合度 | 无量纲 | 抓取语义 |
| Procrustes 形状距 | 去除残余全局旋转/平移/缩放后的形状距 | mm | 分离"形状"vs"尺度/朝向" |

> 建议的"21-DoF 相似度"不是单个数，而是**一个 21 维的误差向量**（每节点 1 维），报告为柱状图/热图：PICO vs 手套在拇指尖、食指尖等处的系统偏置一目了然。这比压成一个 RMS 更有论文价值，也直接回答"相似的不只是腕部轨迹，还有手的 21 自由度"。

### 3.3 整流 / 语义级指标

| 指标 | 定义 | 用途 |
|---|---|---|
| **分离比 separation ratio** | $\rho = \text{median}(d_{same}) / \text{median}(d_{diff})$ | **头号指标**，见 §4.1 |
| 手势分类精度（按设备混排） | 从骨架识别手势的准确率 | 语义可恢复性 |
| 设备识别精度（按手势混排） | 从骨架/腕轨迹识别设备身份 | 越接近随机越好（等价=不可辨识） |
| 有效性/陈旧一致性 | `wrist_dof_mask`/`hand_dof_mask` 在人为丢包下的变化签名 | 降级是否"设备均匀" |

## 4. 核心 + 天马行空但可证伪的实验清单

### 4.1 分离比实验（头号结果，直接对应假设）

对每种语义（腕路径 g、手势 g）收集各设备 canonical 样本，算两个距离分布：

- $d_{same}$：同语义、跨设备（如 PICO 手 vs 手套手的"握拳"骨架距）。
- $d_{diff}$：同设备、跨语义（如手套"握拳"vs"张手"骨架距）。

**结论判据**：$\rho \ll 1$，且 $d_{same}$ 分布与 $d_{diff}$ 分布可被阈值干净分开（报告 AUC / 混淆矩阵）。

- 腕部：4×4 相似矩阵 + 4 种路径的 $\rho$。
- 手部：2×2 相似矩阵 + K 种手势的 $\rho$。

### 4.2 canonical 手势字母表（设备无关的"词汇表"）

定义 K≈8–10 个 canonical 手势（握拳/张手/捏合/指/勾/OK 环/半握/拇指对掌/剪刀…）。每个设备把每个字母各做 N 次。

- **同字母跨设备**：$d_{same}$ 应小。
- **跨字母**：$d_{diff}$ 应大。
- **混淆矩阵**：canonical 骨架 → 手势分类器，accuracy 应高且**不依赖设备**（按设备分层后 accuracy 无显著差）。
- 这同时给 E2/E3 提供"手势预设"的标定库。

### 4.3 盲测：设备身份应当不可辨识（最优雅的等价性证据）

用 canonical 流训练两个轻量分类器：

1. **手势分类器**：输入骨架 → 手势标签，应高精度。
2. **设备分类器**：输入骨架/腕轨迹 → 设备标签，应≈随机（腕 4 类≈25%、手 2 类≈50%）。

> 一句话卖点："**一个好的中间表示，应当让你无法反推它来自哪个设备，却能恢复操作者想做什么。**" 这是领域自适应/公平表示里"域不变表示"的经典判据，直接可写进论文。

### 4.4 传话游戏（cross-device regression / telephone）

设备 A 产生产生 $z_A$ → 把 $z_A$ 当幽灵参照 → 设备 B 追 $z_A$ 得 $z_B$ → 设备 C 追 $z_B$ …。若 canonical 层对设备无损，链条不会累积"设备专属畸变"（只累积操作者追踪误差）。对比：同一设备自追（echo）vs 跨设备追，畸变增长率应无显著差。

### 4.5 同步多模态采集（同手同刻，手部最强证据）

操作者戴手套、PICO 追同一手，同步采 canonical。逐节点误差向量（§3.2）即为"视觉 vs 惯性/编码器"在 canonical 骨架上的系统偏差谱。进一步：

- 变化腕姿（旋前/旋后/抬起）下重复，看偏差是否腕姿无关（这同时是 M2"腕姿参考补偿"的前哨验证）。
- 报告偏差的**设备内可重复性**（同一模态两次测量）作为噪声底，跨模态偏差须显著高于它才叫"真模态差"，否则就是"等价成立"。

### 4.6 距离结构不变性（等距嵌入）

算手势字母表的成对距离矩阵 $\mathbf D$（同设备内）。**等价性要求**：不同设备算出的 $\mathbf D$ 近似成比例/同构（各手势之间的"语义距离"是设备无关的）。检验：$\text{corr}(\mathbf D_{glove}, \mathbf D_{pico})$ 高、且两者对同一 $g_1,g_2$ 的排序一致（Kendall τ）。

### 4.7 流形/降维（可视化 + 量化）

把所有设备的 21 节点骨架拼在一起做 PCA/UMAP：

- **按手势着色** → 应成簇（语义占主导）。
- **按设备着色** → 应混在一起（设备不占主导）。
- 量化：设备身份对前 2–3 个主成分的方差贡献（应远小于手势身份）。前几个主成分应可解释为"开合/拇指对掌/指间张合"等协同变量——这正好接上调研文档 1.3 的"低维协同 + 指级残差"，把 21-DoF 相似性落到"协同子空间相似 + 残差有界"。

### 4.8 脚本化黄金输入的往返一致性（S1 的量化）

参照 $\Delta R(t)$ → 各设备脚本化输入 → $z_d(t)$。报告**每设备固有离散化/量化误差**（键盘步长、摇杆死区、PICO 采样、手套噪声）。结论：$z_d(t)$ 与参照的残差 = 设备固有量化误差（有界、可解释），不含"表示性偏差"。这是"框架等价"的干净证明，也是 paper 2.2 里 $\phi_m$ 设备透明的直接证据。

### 4.9 扰动/降级等价

人为注入丢帧、延迟、断连重连，验证四种条件都通过**同一条 canonical 有效性机制**降级（`stale→mask=0→invalid_reasons`），降级签名（mask 位随时间）设备均匀。这证明"中间态不仅数值等价，其**失效语义**也等价"。

### 4.10 零样本迁移（可选、偏 ML）

用设备 A 的（骨架→手势）标注训练一个轻量映射/分类器，直接在设备 B 的骨架上测试。若迁移精度 ≈ 同设备精度，则表示设备不变。作为 4.3 盲测的补充视角。

## 5. 控制变量与混淆清单

| 混淆 | 控制手段 |
|---|---|
| 操作者技能 | 同操作者、条件顺序拉丁方/随机、正式前 warm-up；多操作者作为跨操作者泛化证据 |
| 绝对锚点 | 全部度量前锚点对齐；S2 幽灵统一起始位姿 |
| 速度/带宽 | DTW 分离形状误差与时序误差；时序误差报告为设备属性，不混入等价性 |
| 时延 | 各设备单独测端到端时延，报告，不混入 |
| 积分漂移 | 腕位姿是积分量；报告漂移趋势项，与形状误差分开 |
| 标定漂移 | 冻结 `hi5_hand_model` / 手套拇指标定 / PICO 外参，记录 `calibration_id`+SHA-256（沿用 SOP） |
| 手模型版本 | 注意 SOP 记录的 v2 vs `config.yaml` 的 v8 不一致，正式取数前冻结并记录生效版本 |
| 镜像/符号 | canonical 已做 quaternion 符号归一与 PICO 镜像，重放验证 `1e-6` 一致 |
| 人为"趋同" | 只测形状/语义距离，不奖励"追得准"，避免操作者把不同设备故意拉成同一速度 |

## 6. 统计边界（沿用 paper 4.4 纪律）

- 50 Hz / 100 Hz 行不是独立样本：用 DTW 后按**段/手势**聚合，报告独立 trial 数、操作者、对象/手势、标定版本。
- 分离比、AUC、分类精度给**置信区间**；连续距离给 median/P95。
- $d_{same}$ 与 $d_{diff}$ 的比较是**配对**（同手势同设备成对），报告配对效应量。
- 先做 **no-send dry-run** 取 canonical 流（SOP 已定义），数据冻结后再算等价；回放一致性（`replay_canonical.py` 通过）是任何等价结论的前置门槛。
- 不填"尚未执行的显著性/最佳阈值/跨操作者结论"。

## 8. 与论文主线的衔接（结论怎么落）

- 这一步把 paper 的"功能命令等价"从**定义**（0.9）变成**可测结论**（§4.1 分离比 + §4.3 盲测）。
- 它不依赖 E2 从端观测器、不依赖闭环辅助，是**纯主端、no-send 可完成**的证据，成本低、可先行。
- 成功标准：腕部与手部都满足 $\rho\ll1$ 且设备盲测≈随机；否则只证明"集成平台"（A1），不能写"命令等价"（对应调研 4.3 的 A1→A2/A3 门槛）。
- 若手部 PICO vs 手套存在**稳定的逐节点系统偏置**（如拇指尖），则它既是等价性缺口，也是下一步 M2"腕姿参考补偿 / 拇指语义映射"的靶点——把"失败"变成下一轮消融的输入。

## 10. 补充实验与记录清单（10 trials × 4 条件、同任务的配套）

> 前提声明：E1 阶段 perception 观测器保持冻结不动（其逻辑调整归 E2），E1 结论不使用观测器状态作为证据，只使用 canonical 层与从端执行指标。

### 10.1 必做（高收益、低成本）

**A. 把"同一个任务"冻结成带锚点的任务脚本（任务可分段，是 10-trial 统计的前提）**
- 空间路标：水槽/工作区放 3–4 个编号立柱或固定物，任务 = 按固定顺序访问路标 + 固定位置的目标物。
- 手势节点：每个路标绑定一个手势（张开 → 半握 → 包覆 → 保持 → 张开），显示器按节奏提示。
- **必须包含一段 roll/J4 动作**（如"在路标 2 处腕转 ±30°"），否则 5-DoF 只覆盖 4-DoF（现有数据键盘/手柄 roll 全程为 0）。
- 每个路标到达时按一个专用"标记键"（或记入事件日志），给离线分段提供时间锚点——免费的 segment 标签。
- 任务定义（物体规格、路标坐标、手势列表、节奏、标记键）写入 SOP 冻结项。

**B. 同刻双模态手部采集（手 21-DoF 等价的最硬证据）**
- 操作者**同时**戴 Hi5 手套且 PICO 追踪同一只手跑任务（腕可用 VR 手柄驱动）。
- 前提：确认 `raw_input.jsonl` 能同时记录 `data_glove` 与 `pico_hand` 两路（若浏览器只转发选中源，加一个"记录全部手源"开关，改动极小）。
- 离线比较两路各自映射得到的六维 WA100 值，并统一用 `WA100Kinematics.canonical_skeleton_21()` 重建 21 点骨架 → 同真值、同刻的六维误差和逐点偏置谱。
- 注意：canonical 主手源仍按条件只选一路，另一路仅作为记录旁路，不改变控制。

**C. 手势字母表协议（给手部数据打免费标签）**
- 10 个手势 × 每手势保持 3 s × 每条件重复 ≥3 遍，提示由显示器给出 → 手势标签不需要人工标注。
- 产出：分离比 ρ、跨设备混淆矩阵、设备盲测（§4.1/§4.3）、距离结构不变性（§4.6）。

**D. 10-trial 三层距离表（E1 头号统计表，离线脚本即可）**
- 对每对 trial 算 DTW 腕轨迹距离与骨架 RMS：**同条件重复 / 跨腕设备（同手套）/ 跨模态（PICO vs 手套）** 三层。
- 判据：跨设备距离与同条件重复距离同量级（等价成立）；跨模态距离显著更大（手部边界，喂给 M2）。

**E. 时延与设备属性表（无需新记录，从已有字段直接出）**
- `source_state.wrist_age_sec/hand_age_sec` 每行已有 → 每条件输入到 canonical 的时延中位/P95。
- 每条件：完成时间、路径长、输入事件数、delta 占空比、PICO 跟踪丢失率（`wrist_dof_mask=0` 比例）——全部作为**设备属性**单独报告，不混入等价性指标。

### 10.2 强烈建议

**F. 脚本化黄金输入等价测试（框架等价的确定性证明，无操作者方差）**
- 对同一条语义意图序列 ΔR(t)（腕平移+roll+手关键帧），写每设备的脚本化驱动器（键盘定时按键、手柄脚本化摇杆、VR 脚本化增量、PICO 脚本化位姿），验证四条 canonical 输出在各自量化误差内一致。
- 实现方式：在浏览器端加一个"脚本回放"测试页，或按 mapping 版本（`ui-*-mapping-v*`）在 Python 复刻各设备映射做离线往返；二选一。

**G. 幽灵跟随参照轨迹（可选但直接回答"相似轨迹"）**
- 在 VR/sim 显示一条低速 ghost 轨迹，操作者用每种设备追它 → 参照 R(t) 唯一，跟踪误差 = 设备表达能力的上界。键盘/手柄只能低速追，把 ghost 速度压到键盘步进可跟。

**H. 实验顺序与穿戴纪律**
- 4 条件 × 10 trial 用区组/随机顺序（禁止"一个条件连做 10 次再换"）；同条件块内**不摘手套**（重复穿戴是最大的手部混淆）；每块开始前记录手套拇指标定 `calibration_id`、`closure_gain`、手模型 SHA——manifest 已带，补一张纸质/电子台账即可。

### 10.3 可选（锦上添花）

- 屏幕录制（浏览器 UI 的 canonical 骨架叠加画面），供事后人工核对"同一手势"；
- 记录每 trial 的 `hand_target_units` 动态（路径长/速度），用于解释手 RMSE 的模态差异（PICO 目标动态 ≈ 手套 10×）；
- 对 PICO 单独补录重复 trial（现有水下数据 PICO 只有 1 次，其余条件 2–4 次）。

### 10.4 明确不做

- E1 不改 perception 观测器逻辑（冻结，归 E2）；其状态记录照常落盘但仅作 E2 素材；
- E1 不写"抓取成功"类结论（无人工/视觉标注判据）；
- 不给等价性指标填尚未执行的显著性数字。
