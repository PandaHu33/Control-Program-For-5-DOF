> 数据：`control_ui/recordings/20260818/` 下四组约 43–60 s 的 send-mode 通用录音（`task: general_recording, success: unknown`）
> 分析脚本：`analysis_outputs/e1_canonical_equivalence/analyze_e1_{sessions,stage2,stage3}.py`
> 产出：`e1_sessions_summary.json`、`e1_stage2_report.json`、`e1_stage3_report.json`、`wrist_path_overlay.png`、`hand_flexion_profiles.png`、`wrist_delta_histograms.png`
> 关联：[E1_CANONICAL_EQUIVALENCE_DESIGN.md](E1_CANONICAL_EQUIVALENCE_DESIGN.md)、[E1_CANONICAL_DRY_RUN_SOP.md](E1_CANONICAL_DRY_RUN_SOP.md)

## 0. 一句话结论

> 这四组数据**能作为 E1 的"可行性 + 中间态结构统一 + 模态偏置刻画"预实验证据，不能作为"同一轨迹 → 相同中间态"的等价性证明**——因为四段录音是四段自由操作，没有公共参照轨迹，手势也没有对齐。它证明了"四种主端都能在我的框架下产生同结构、同质量、可执行的 canonical 中间态"，还意外地给出了 PICO 视觉 vs 数据手套的逐关节模态偏置图。包装定位应是 **E1-P0 预实验（feasibility & modality-bias characterization）**，而不是 E1 等价性主结论。

## 2. 先回答一个关键事实：这四段"跑的是不是同一条轨迹"？——不是

| 证据 | 数值 | 含义 |
|---|---|---|
| 时长不一致 | 60.6 / 56.2 / 43.0 / 43.3 s | 不是同一时间脚本 |
| 腕轨迹形状相关（时间归一化后） | 键盘↔手柄：x 0.94 / y 0.84 / z 0.97；键盘/手柄↔VR：0.27–0.58；VR↔PICO：x **−0.26** | 只有键盘与手柄互相"重演了相似路径"；VR/PICO 是另外的自由轨迹 |
| 手指屈曲序列相关 | 键盘↔手柄 0.73–0.74；手套↔PICO 中指 PIP 0.11–0.40、拇指 MCP ≈0 或负 | 手势序列没有跨会话对齐 |
| 腕部最大位移 | **0.248 / 0.251 / 0.268 / 0.248 m** | 同一操作者、同一工作空间包络（一致性苗头，见 §4） |

**结论**：这批数据没有"公共参照轨迹"，所以不能用它来算"同轨迹 → 同中间态"的分离比/等价性指标。想用它硬写等价性，会被审稿人一句"轨迹根本不一样"驳回。

## 3. 它真正证明了什么（三层，从硬到软）

### L1 · 可行性：四种异构主端 → 一条完整 canonical 流（系统集成事实）

- 四种 `(wrist_source × hand_source)` 组合全部产出 `canonical_goal`，50 Hz，21/21 手掩码、腕掩码 15，标定 ID/SHA 冻结一致；
- 零 seq 丢失/重复/乱序；`valid_samples = 100%`；回放一致性可由 `replay_canonical.py` 复核；
- 从端臂手都真实执行了中间态命令。

**写法**："系统在四种主端条件下均端到端生成同构、完整、可回放的中间语义流"——这是 E1 SOP dry-run PASS 判据的核心，也是论文 §2.2 "平台无关共同命令语义"在**流结构层面**的第一手证据。

### L2 · 结构统一 + 设备签名只残留在输入端（本批数据最有价值的发现）

中间态的**结构与质量**不随设备变化；设备身份只在**输入量化特征**里留下可测、有界的签名：

| 设备 | 腕增量事件数 | 步长分位 mm (p5/p50/p95) | 运动占空比 | 平均/峰值速度 mm/s | 旋转 |
|---|---|---|---|---|---|
| 键盘 | 129 | **10 / 10 / 10** | 4.4% | 23 / 2455(瞬时阶跃) | 0 |
| 手柄 | 161 | 2.3 / 8.4 / 10.5 | 6.0% | 22 / 895 | 0 |
| VR 手柄 | 331 | 1.1 / 5.0 / 14.1 | 15.7% | 49 / 1293 | 16.4° 范围 |
| PICO | 347 | 0.5 / 3.6 / 15.2 | 16.2% | 43 / 3209 | 17.3° 范围 |

- 键盘增量**精确等于 10 mm 一步**（p5=p50=p95=10.0 mm），是离散输入的完美量化签名；手柄是摇杆的连续但分档；VR/PICO 是平滑小步。
- 但所有这些签名最终都被积分进**同一条连续腕位姿流**，下游 `arm_target_q_rad` 与从端执行误差在四种条件下同量级（目标-实测差 ≈0.01–0.05 rad）。
- PICO 腕跟踪中途掉线 4 次（共 ~5.4 s），canonical 层自动把 `wrist_dof_mask` 清 0、恢复后回 15——**失效语义跨设备统一**，其他三种设备未触发。

**写法**："异构性被约束在输入端并量化为有界步长/占空比差异，中间态在结构、频率、有效性和降级语义上设备无关；设备身份无法从中间态的结构推断，只能从输入量化残差推断。"

### L3 · 一致性苗头 + 手部 21-DoF 模态偏置（诚实的"半正半负"结果）

**苗头（支持等价方向）**：
- 同一操作者、同一工作空间包络：四条件腕最大位移惊人一致（0.248–0.268 m）；
- 三个手套会话的指尖距离互相一致（拇指 119.4–122.5 mm、食指 146.3–153.7 mm……会话间差 <8 mm），即"同一只手做相似动作 → 手套侧 canonical 骨架可重复"；
- PICO 的指尖距离与手套差 **6–13 mm**（PICO 偏短，与手模型名 `v8-pico-scale` 的缩放标定一致）；
- 两种模态在"手指屈曲发生在 PIP/DIP、MCP 基本不动"上一致（两者 MCP 变化范围都 ≈0–4°）。

**偏置（暴露 21-DoF 等价尚不成立）**，PICO 视觉相对数据手套的逐关节系统差：

| 关节 | 手套均值(°) | PICO 均值(°) | 偏置 | 解读 |
|---|---|---|---|---|
| 拇指 MCP | 52–58 | 19.5 | **≈ −35** | 视觉把拇指"拍平" |
| 食指 DIP | 14–21 | 35.7 | +15–21 | 视觉指尖过度内扣 |
| 中指 DIP | 11–21 | 33.3 | +13–23 | 同上 |
| 无名指 DIP | 11–21 | 28.9 | +8–18 | 同上 |
| 小指 PIP | 4.5–11 | 20.8 | +9–16 | 同上 |
| 食指/中指 PIP | 32–39 / 25–30 | 35.3 / 23.1 | ≈0 | **一致** |

**写法**：这不是失败，而是"21-DoF 等价性的第一张误差谱"——它把抽象的"手部相似"落成逐关节可测偏置，直接标出 M2（腕姿参考补偿/重定向）需要修的靶点（拇指 pitch/yaw、远端指节过屈），并且给出"协同子空间（PIP、开合、指尖距离）已接近一致，高阶残差（DIP/拇指）仍带模态偏置"这一与论文协同—残差框架完全对得上的叙述。

## 4. 它不能证明什么（边界，写进报告里避免被审稿人抓）

1. **不能证明"不同主端跑相似轨迹 → 中间态相似"**（用户的 E1 主假设）——缺公共参照轨迹；腕轨迹形状相关跨条件只有 −0.26~0.58。
2. **不能证明手部 21-DoF 的 PICO↔手套等价**——非同刻采集、无手势标签、逐关节偏置高达 35°。
3. **不能证明 5-DoF 中的旋转自由度等价**——键盘/手柄会话旋转增量恒为 0（总旋转变化仅 5.7°/8.6°，来自锚定），只有 VR/PICO 动了腕旋转。
4. 不是 SOP 意义上的 E1 dry-run：`no_send: false`，从端真实运动了（SOP 要求 dry-run 无执行器运动）。要按 SOP 冻结，需用 no-send 开关重录一遍（或明确记录为"通用录音、非 dry-run"）。
5. 每条条件只有 1 个 trial，无重复统计，无操作者/手势标注——不能报显著性。

## 5. 怎么包装：定位与结构建议

### 5.1 定位

> **E1-P0 预实验报告：异构主端 canonical 中间态的可行性、结构统一性与手部模态偏置刻画**
> 英文可写为 *Preliminary evidence for a device-independent canonical command layer across four master interfaces, with per-DoF hand-modality bias characterization*。

它对应的论文位置是 E0/E1 之间的"系统事实 + 消融靶点"小节，不是主结果。

### 5.3 结论段（可直接改写成论文语言的骨架）

> 在四种异构主端条件（键盘/手柄/VR 手柄/PICO 视觉）下，系统均以 50 Hz 生成完整、有效、可回放的 canonical 中间态（腕 5-DoF + 手 21 节点），seq 零丢失、标定冻结一致、从端跟踪误差同量级；设备间差异以有界输入量化（10 mm 键盘步长、占空比、速度分布）形式保留在输入端，中间态本身在结构与失效语义上设备无关。手部两种传感模态在协同子空间（PIP 屈曲、指尖距离、开合）已接近一致，但在高阶指节（DIP 过屈 8–23°）与拇指 MCP（−35°）存在可测模态偏置，这为参考系补偿与跨模态重定向提供了明确的标定靶点。上述结果支持"平台无关共同命令语义"的结构性成立，但尚不构成同轨迹等价性与 21-DoF 模态等价性的完整证明。

## 6. 补成"正式 E1 等价性证据"还缺什么（对照 DESIGN 文档）

按 `E1_CANONICAL_EQUIVALENCE_DESIGN.md` 的清单，这四组数据差的就是：

1. **公共参照轨迹**（S2 幽灵跟随，或 S1 脚本化黄金输入）：让四种设备跑同一条 canonical 轨迹，才能算分离比 ρ；
2. **同刻多模态采集**（S3）：手套 + PICO 同时盯同一只手——直接把 §3 L3 的"偏置"升级为同真值下的模态误差；
3. **手势字母表标注**：给指尖距离/屈曲序列打手势标签，才能出跨设备混淆矩阵与设备盲测；
4. **旋转自由度**：键盘/手柄会话要补 J4/腕旋转动作，否则 5-DoF 只证了 4-DoF；
5. **no-send dry-run 重录**：按 SOP 用 no-send 开关重录四条，满足"无执行器运动"的冻结判据；
6. **重复 trial**：每条件 ≥3 次，报告置信区间。

其中 1 和 5 可以合在一次录制里完成（no-send + 幽灵跟随），成本最低、直接补上最缺的"公共轨迹"。
