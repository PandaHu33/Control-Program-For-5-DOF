# 5-DOF 水下机械臂-灵巧手遥操作控制程序（主端）

面向 5-DOF 水下机械臂与 WA100 灵巧手的遥操作实验主端程序。系统以本地 Windows 主端为核心，通过 Jetson（ROS1）驱动机械臂，通过串口 SDK 驱动 WA100 灵巧手，并整合 Unity 数据手套、VR 手柄、双路 USB 相机与多模态数据记录，提供浏览器 H5 显控界面。

> **E1 实验入口：** P0/E1 四条件在正式试次前必须按 [E1 Canonical no-send dry-run SOP](docs/E1_CANONICAL_DRY_RUN_SOP.md) 完成检查。MATLAB 主手不在本轮范围内；P1/P2 与 E2 仍为 `BLOCKED`。未确认 no-send、来源/掩码/标定和回放均通过前，禁止使能正式发送。

## 系统组成

| 目录 / 子模块 | 说明 |
| --- | --- |
| `control_ui/` | 浏览器 H5 显控界面：WebSocket UDP 桥接、机械臂/灵巧手状态与控制、双路相机显示或 RTSP/HLS 推流、多模态记录服务、episode 回放、感知/一致性辅助监控、WA100 本地运动学、一键启动脚本 |
| `Hand_Tracker/` | 本地手部识别服务：相机手势/骨骼控制、Unity XR 手腕增量控制、主手腕部融合（手柄 + Hi5 手套） |
| `wa100-sdk-publish/` | WA100 灵巧手 SDK 子模块：C++ 驱动接口、Unity UDP 接收、手套拇指映射与标定、原始手部输入遥测 |
| `DataSet_ws/` | Jetson 端 ROS1 工作空间：机械臂节点 `mainpulator`、`h5_udp_bridge`、ROS-TCP-Endpoint、`usb_cam`（子模块） |
| `protocol/` | 通信协议定义：帧编解码、canonical goal 与感知辅助状态 JSON Schema |
| `robot/` | Jetson 端机械臂启停/检查脚本 |
| `sim/` | 远端机械臂仿真器（无硬件时调试用） |
| `right1/` | Unity 数据手套程序（`My project.exe`） |
| `deployment/` | Jetson ROS1 部署包 |
| `docs/` | 实验 SOP 与调研文档 |
| `tests/` | 主仓库自动化测试 |

## 快速开始（一键启动）

1. **机械臂上电**：将机械臂电源开关拨到右侧上电。
2. **灵巧手上电**：连接灵巧手电池并上电。
3. **连接数据手套**：点击手套按钮，绿灯快闪表示已连接。
4. **启动程序**：打开程序文件夹，运行一键启动脚本（`control_ui/one_click_start.bat`，首次使用建议先运行 `run_ui.bat` 完成 SSH 免密配置）。
5. **允许相机权限**：浏览器弹出相机授权时选择允许。此时会另外弹出 3 个窗口，保持后台运行即可。
6. **确认就绪**：成功启动后显示显控界面；启动窗口中出现 `System is ready` 表示机械臂节点已在线。若显示 `H5 is open, but arm nodes are not fully online`，请勿操作机械臂并联系工程人员检查 Jetson 节点；若显示 `FAIL`，请保留窗口内容并拍照反馈。

## 双摄像头模式

- 默认使用「显控显示」：浏览器上下显示两路摄像头画面，不启动 RTSP/HLS 推流；首次使用需允许浏览器访问摄像头。
- 在「双摄像头」卡片中选择「显控显示」或「推流」，点击「保存为下次启动模式」，关闭并重新运行一键启动后生效。
- 「推流」模式将两路画面上下拼接并在网页中同步监看。RTSP 地址：`rtsp://192.168.3.10:8554/usb_camera`；本机 HLS 地址：`http://localhost:8081/usb_camera/index.m3u8`。
- 若只显示一路，请检查对应状态提示、USB 连接与浏览器摄像头权限；另一路不会因此被关闭。

## 控制方式

- 默认为**键盘控制**，点击手柄可切换为**手柄控制**。使用手柄控制前，请确认界面下方显示 `xbox 360 Controller`（手柄已连接），否则请勿切换！
- `位置控制`：按末端 XYZ 位置目标控制。
- `关节控制`：按三个关节目标控制。
- `W/A/S/D`：键盘模式下控制前后左右。
- `Q/E`：键盘模式下控制上下。
- `左摇杆`：手柄模式下控制前后左右。
- `L/L2`：手柄模式下控制上下，`L` 下降，`L2` 上升。

> 机械臂预设位置中只有「初始位置」可发送（与复位键为同一位置），其余位置请勿点击发送。

### 状态提示

- 若显示「已达到工作空间外边界，目标被限制」：需要往回运动。
- 若显示「已达到内肘/自碰安全边界，目标被限制」：需要往外运动。

## 复位与关机

- 点击**复位**按钮可复位机械臂和灵巧手到初始位置（复位前确认运动过程中不会发生碰撞）。
- 结束实验后，点击**关闭系统**关闭所有后台程序；确认全部程序关闭后，关闭显控网页界面，并为各设备（机械臂电源、灵巧手电池）断电。

## 显控界面按钮说明

### 顶部按钮

- `切换到 Debug`：进入调试界面，显示隐藏的节点、网络、日志和主手/Simulink 相关调试项。
- `切换到 Main`：从 Debug 返回主界面。

### 系统控制

- `板卡重启`：通过 SSH 向 Jetson 发送重启命令。
- `初始化`：拉起系统所需节点和本地程序，包括 Jetson 节点、UDP 桥接、本地灵巧手程序和数据手套程序。
- `复位`：机械臂回到零位目标，灵巧手回到复位位置。
- `关闭系统`：停止 Jetson 节点、UDP 桥接和本地手/手套程序。
- `急停`：发送停止命令，机械臂和灵巧手保持当前状态，节点不关闭。

### 本地控制输入

- `键盘`：使用键盘作为机械臂输入源。
- `手柄`：使用 USB 有线手柄作为机械臂输入源。
- `位置控制`：按末端 XYZ 位置目标控制。
- `关节控制`：按三个关节目标控制。
- `W/A/S/D`：键盘模式下控制前后左右。
- `Q/E`：键盘模式下控制上下。
- `左摇杆`：手柄模式下控制前后左右。
- `L/L2`：手柄模式下控制上下，`L` 下降，`L2` 上升。

### 机械臂预设位置

- `初始位置 - 发送`：按当前输入框角度发送初始位置目标。
- `预抓取 - 发送`：按当前输入框角度发送预抓取目标。
- `抓取姿态 - 发送`：按当前输入框角度发送抓取目标。
- `释放姿态 - 发送`：按当前输入框角度发送释放目标。

### 灵巧手 / 数据手套

- `启动灵巧手 exe`：启动本地灵巧手控制程序。
- `重启灵巧手 exe`：关闭并重新启动本地灵巧手控制程序。
- `灵巧手状态`：检查灵巧手程序状态。
- `启动 Unity 数据手套`：启动本地数据手套程序。
- `数据手套状态`：检查数据手套程序状态。
- `链路状态`：检查本机手/手套 UDP 链路。
- `手套操控模式`：切换灵巧手到手套随动模式。
- `预编程位置模式`：切换灵巧手到预设位置控制模式。
- `复位 2000`：灵巧手全部关节回到 2000。
- `半握`：发送半握预设。
- `握拳`：发送握拳预设。
- `捏取`：发送捏取预设。
- `钩拉`：发送钩拉预设。
- `发送自定义位置`：按 6 个输入框中的数值发送灵巧手位置。

## Debug

调试界面显示隐藏的节点、网络、日志和主手/Simulink 相关调试项，供工程人员排查问题使用。

## 自动化测试

主仓库与 WA100 子仓库均带自动化测试（`tests/`、`wa100-sdk-publish/tests/`），覆盖控制仲裁、记录服务、相机启动模式、手部通道布局、主手融合、原始输入校验、WA100 运动学与反馈过滤等。当前基线：主仓库 120 项通过 / 3 项跳过；WA100 7 项 Python 测试与 3 项 C++ 测试通过。
